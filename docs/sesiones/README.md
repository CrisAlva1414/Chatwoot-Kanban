# Sesiones

Cada archivo resume una sesión de trabajo. Sirve para que el LLM retome
contexto rápidamente sin tener que releer conversaciones enteras.

## Formato

```
<NUMERO>-<FECHA>-<TEMA>.md

001-2026-07-09-inicializacion-y-arranque.md
```

## Contenido de cada sesión

1. **Contexto** — por qué se trabajó en esto
2. **Qué se hizo** — resumen puntual de cambios
3. **Archivos tocados** — rutas relevantes
4. **Decisiones tomadas** — vínculo a ADR si aplica
5. **Próximo paso** — qué sigue (para que el LLM sepa por dónde arrancar)
